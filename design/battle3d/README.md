# 3Dバトルのモデル

- `bunk_tripo_original.glb`：企画者がくれた BUNK の3Dモデル（Tripo で作成・2026-11-01）。元のまま残す（約100万頂点・16.9MB・骨なし・動きなし）。
- ゲームで使うのは軽くしたもの：`public/assets/battle3d/bunk.glb`（約4万三角形・絵は1024・webp・1.05MB）。見た目は元とほぼ同じ（比べた画像で確認）。
- 軽くする手順（gltf-transform 4.1.1。プロジェクトには入れず、作業用の場所で使う）:
  ```
  gltf-transform optimize bunk_tripo_original.glb bunk.glb --compress false --simplify-ratio 0.02 --simplify-error 0.002 --texture-size 1024 --texture-compress webp --instance false --join false --palette false
  ```
- 向き：前が +x、上が +y（ゲームと同じ）。高さ 約0.87 → ゲームでは 約1.55 に大きくする。
- 骨（関節）がないので、手足は別々に動かない。体全体を跳ねさせる・つぶす・かたむける・回す動きだけ。手足を動かすには、骨入れ（リギング）と動きのデータが必要。

## 骨入りのモデル（2026-11-01）
- `bunk_tripo_rigged_original.glb`：企画者が Tripo のオートリグで骨を入れたもの（元のまま・17.6MB・動きのデータなし）。
- ゲームで使うもの：`public/assets/battle3d/bunk.glb`（同じ手順で軽くした。骨とウェイトはそのまま・1.29MB）。前の骨なしの軽い版は `unused/bunk_static_light.glb` に移した。
- 骨を調べた結果：
  - 骨は78本（腰・背中2・首・頭・目・肩・腕・手・指5本ずつ・足・すね・足先）。人の形の骨。
  - すべての頂点にウェイトが付いている（抜けなし）。
  - **問題1**：右の肩・右の上の腕の骨が、頭のてっぺん（右の耳のあたり）まで動かす。腕を大きく動かすと、顔と体がゴムのようにのびて形がくずれる。
  - **問題2**：左右の骨の位置がそろっていない（左の太ももの骨が体のまん中・右の腕の骨が高い）。
  - **問題3**：指の骨がグローブの一部を動かす（指は動かさない）。
  - 足・背中・頭は、小さく動かせば形がくずれない。
- そのため、骨の動きの大きさに上限を付けた（`src/render/bunkBones.ts` の SAFE。腕0.25・足0.4・背中と頭0.15 ラジアン）。
- パンチなど腕を大きく振る動きをきれいに出すには、ウェイトの直し（右の腕の骨が頭を動かさないように）が必要。

## 右腕の骨の直し（2026-11-01 企画者「直してOK」）
- 元：`bunk_tripo_rigged_original.glb`（書き換えていない）。直したもの：`bunk_tripo_rigged_fixed.glb`（別ファイル）。直す手順：`fix_rig.mjs`（gltf-transform 4.1.1・gl-matrix 3.4.3。作業用の場所で `node fix_rig.mjs 元.glb 出力.glb`）。
- 直したこと：
  1. ウェイト：右側の上半身（z>0・高さ0.18より上。境目はなめらかにつなぐ）の頂点に、左右反転した左側の頂点のウェイトを写した（左右の骨の名前を入れかえ）。1つの頂点のウェイトの合計は 1（全頂点で確認）。37万頂点を書きかえ。
  2. 右腕の骨（肩・上の腕・前の腕・手）の回る中心を、左腕の左右反転の場所へ動かした（向きは変えない）。逆バインド行列を計算し直したので、立ち姿の形は元と同じ。
- 確かめたこと：右腕で動く所が腕だけになった（頭・顔・右耳はもう動かない）。腕を上げる・パンチ・フック・体のひねりで顔がくずれない。立ち姿は元と同じ（軽くした版の画像のちがいは 0.16% の点だけ・軽くするときの差）。
- 左右の形が少しちがう所（腕のわき・高さ0.3〜0.5）は、左右反転の相手が2cmより遠い頂点があった（約2割）。頭・顔にはない。
- まだ直していない：左の太ももの骨がまん中にある・頭の骨が顔の大部分を動かさない・肩の骨が胴体の広い所を動かす（腕を0.9ラジアンくらい大きく振ると、左右どちらものびる）。
- ゲーム用：`public/assets/battle3d/bunk.glb`（直したものを軽くした・1.62MB）。直す前の軽い版は `unused/bunk_rigged_light_before_fix.glb`。

## BUNKER（BUNK の第1進化・2026-11-02）
- `bunker_tripo_rigged_original.glb`：企画者がくれた骨入りモデル（Tripo オートリグ・動きなし・元のまま）。ゲーム用：`public/assets/battle3d/bunker.glb`（同じ手順で軽くした・1.34MB）。
- 骨は BUNK と同じ78本。**左右の骨の位置はそろっていて、BUNK の右腕のような問題はなかった**ので、直していない。
- 両方の肩の骨が、耳を少し動かす（左右同じ）。ゲームで使う腕の角度では、ほとんど目立たない。
- 右パンチ・左パンチ・足・体のひねりで、顔と体がくずれないことを確かめた。
- 骨の名前が BUNK と同じなので、待機・移動・腕の攻撃の動き（`bunkBones.ts`）がそのまま使える。

## BUNKLORD（BUNK の第2進化・2026-11-02）
- `bunklord_tripo_rigged_original.glb`：企画者がくれた骨入りモデル（元のまま）。ゲーム用：`public/assets/battle3d/bunklord.glb`（軽くした・1.45MB）。
- **骨が大きくずれている**（オートリグが毛皮の上着・とげの腕輪で迷ったと思われる）：
  - 右腕の骨 → 頭・とさか・右の耳を動かす（右のグローブは動かさない）。右の手の骨が頭の高さ（0.66）にある
  - 右足の骨 → 右のグローブを動かす（右の太ももの骨が胸の高さ 0.56）
  - 頭の骨 → 左にずれていて（z −0.2）、左肩の毛皮を動かす
  - 左腕・左足は正しい
- そのため、ゲームでは**骨を動かさない**（`roster.ts` の `MODEL_NO_BONES`）。体全体の 跳ねる・かたむく・回る だけで動かす。形はくずれない。
- 直す方法の案：①Tripo でオートリグをやり直す（腕を少し体から離したポーズにすると良いことが多い）②こちらで直す（左側の骨とウェイトを左右反転して右側へ。BUNK の右腕と同じ方法。ただし頭の骨もずれているので、BUNK より直す所が多い）
