## 7. 種族の比べ・重なり

`docs/techs_draft_tables.md`（自動で作る）を見る。主なこと：
- 「当たった時のダメージ ÷ 待ち時間」は どの種族も 3.4〜4.3 の間（BUNK は 3.4〜3.6）。差は 型・追加効果・回復などで出る。
- 遠くからの技：KLAK 11 がいちばん多い。GRIT 2 がいちばん少ない（近づくのが苦手 → 守りで受けて返す型）。
- 追加効果つき：SNEK 12/17 がいちばん多い（重ねがけに注意）。
- 重なりが多い：KLAK の設置4・GRIT の守り4・RIOT の突進4・MOFU の守り3と回復3。
  - 案：KLAK の トラップチェイン を「連射」に、GRIT の かたまりガード を「強化（その場で受けるダメージ減）」に、RIOT の アバレダッシュ を「回転」に、MOFU の わたぐもカーテン を「設置（綿雲の壁）」に。
- 型・属性・強さが まったく同じ組：ジグザグスピン／電光スパイラル（ZIPP）、ぷるんガード／ぷにぷにウォール（PUNI）、爆牙クラッシュ／灼熱猛進（RIOT）、ポイズンドロップ／毒霧迷路（SNEK）、バブルフィールド／水流トラップ（SHELLZ）。
  - 案：動き方を変える（例：電光スパイラル は その場で回る竜巻、毒霧迷路 は 壁の形）か、強さを変える。
- 弱体の効果が同じ：ナイトウィスパー／ナイトブラインド（SNEK）、ノイズパルス／ノイズジャマー（VYBE）→ 新しい効果（防御ダウン・ためが長くなる）を使えば分けられる。
- Lv.70 は 設置4・守り2（PUNI と GRIT）。PUNI の 万象ぷにドーム は BUNK の ガンジョウドーム（反撃）と似ている → ためた分だけ大きく返す・ドームが大きい、で分ける。
