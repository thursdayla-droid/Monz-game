# MONZ 麻雀RPG（ミニゲーム④）

2026-11-08 企画者の仕様書 Ver.1.0 を受けとった。名前は **麻雀クエスト**（2026-11-09 企画者の タイトルの 絵。前は MAHJONG QUEST）。イメージの 絵は design/mahjong/concept_v1.png。
この文書は 仕様書の 要点と、作る順番（Claude の 案）をまとめる。**仕様書に ない ルールは 勝手に 決めない。**

## 1. 仕様書の要点

### 1.1 麻雀【確定】
- 日本式 四人打ち リーチ麻雀。プレイヤー1人＋CPU3人（ボス1人＋子分2人）。136枚
- チー・ポン・カン、リーチ・ドラ・裏ドラ・カンドラ、通常役〜役満、符・翻・点数計算、親あり、ロン・ツモ
- **ルール・点数計算を簡略化しない**

### 1.1.1 細かい ルール（2026-11-08 企画者）
- 赤ドラ あり（赤い5。枚数は 各色1枚ずつ＝3枚【仮：おすすめどおり】）
- 喰いタン あり
- 九種九牌：プレイヤーは 流すか 選べる。CPU は 必ず 流す
- ダブル役満 あり・数え役満 あり
- 半荘（東場・南場）
- 親が 続く 決まり（連荘・本場）は ふつうの 麻雀と 同じ
- 半荘が おわったら ウマを つける。使うのは プレイヤーの ウマだけ（プラスは 敵へ・マイナスは 自分への ダメージ。CPU の ウマは なし）。大きさは【仮：1位 +10,000・2位 +5,000・3位 −5,000・4位 −10,000】
- HP が 残って いれば 次の 半荘へ。点数は 25,000に 戻さない。敵を 倒すか やられたら 終わり（2026-11-08）
- 飛び なし：勝ち負けは HP だけで 決める。麻雀の 点数が 0 より 下に なっても 続ける。点数が 足りなくても リーチ できる（2026-11-08 企画者 OK）
- ほかの 途中流局（四風連打・四家立直・四槓散了・三家和）は なし
- 流し満貫 あり（満貫ツモと 同じ 点・ノーテン罰符なし。ダメージも ツモと 同じに する【仮】）
- ダブロン あり（2人とも アガリ）
- 責任払い（パオ）は なし
- 西入・アガリやめは なし

### 1.2 HP【確定】
- プレイヤー HP 30,000／敵チーム HP 30,000（CPU3人で共有。個別HPなし）
- 敵HP 0以下でクリア、プレイヤーHP 0以下で負け。ステージが進むと敵HPを増やす予定

### 1.3 ダメージ【確定】
| 場面 | ダメージ |
|---|---|
| プレイヤーが ボスから ロン | アガリ点の 100% を敵へ |
| プレイヤーが 子分から ロン | アガリ点の 100% を敵へ（2026-11-09 企画者「半分じゃなくて いい」。前は 50%） |
| プレイヤーが ツモ | CPU3人の 支払いの 合計を敵へ（50%補正なし） |
| CPU が プレイヤーから ロン | アガリ点の 100% をプレイヤーへ |
| CPU が ツモ | プレイヤーが 払う 点を そのまま プレイヤーへ |
| CPU どうしの ロン | 麻雀としては 成立・プレイヤーへの ダメージなし【暫定】 |
| 流局の テンパイ料 | プレイヤーが もらった 分は 敵へ・払った 分は プレイヤーへ（2026-11-09 企画者） |

積み棒・供託・CPUどうしの点の動きは【未確定】（エンジンを作る時に整理）。

### 1.4 ステージ【基本方針確定】
- STAGE 1 から順に。STAGE 1 はアイテムなし。クリアでゴールド・道具屋が開く
- STAGE 2 以降：開始前に アイテムを 1個 えらんで 使える。敵HP・CPUの強さが 上がる
- 総ステージ数・敵HPの増え方・報酬は【未確定】

### 1.5 道具屋とアイテム【基本方針確定・中身は提案】
| アイテム | 値段【仮】 | 効果 |
|---|---|---|
| こんぼう | 100G | 次のアガリの ダメージ2倍（子分ロンは 半分にした あとで2倍）〔企画者指定〕 |
| やくそう | 150G | 次のアガリで 与えた ダメージと 同じだけ 回復（最大HPまで）〔企画者指定〕 |
| てつのたて | 120G | 次に 受ける ダメージ 50%減【提案】 |
| こううんのおまもり | 200G | 次のアガリに +3,000【提案】 |
| まほうのたま | 250G | 次のアガリに 敵の最大HPの 20% を追加【提案】 |

使い方【提案・変えやすく作る】：1ステージ 1個まで・開始前に使う・使うと 1個減る・条件を満たすまで 続く・攻撃系は 次のアガリ／防御系は 次に ダメージを 受けた時・1回で おわり・使わずに ステージが おわっても 消える。

### 1.6 画面
タイトル／ステージえらび／道具屋／持ち物／開始前の アイテムえらび／対局（横画面・中央に卓・下に 自分の手牌・上左右に CPU・ボスが わかる・HPバー2本・大きな ダメージ数字・アイテム演出）／アガリ演出／クリア／ゲームオーバー。
見た目は MONZ と同じ アニメ調（太い輪郭・紫・オレンジ・金・ストリート）。満貫・跳満・倍満・役満で 演出を 強く。

### 1.7 未決定（勝手に 決めない）
正式名称・総ステージ数・各ステージの敵HP・ゴールド報酬・値段・アイテムの細部・CPUどうしのアガリ・流局／連荘／本場／供託・HP回復と最大HP・負けた時の ペナルティ・途中セーブ。

### 1.8 お金（2026-11-08 企画者）

- 1ゲーム目は 0G から。STAGE 1 に 勝って もらった G で アイテムを 買う

## 2. 今の MONZ への 入れ方（Claude の案）
- ミニゲームの 4つめの 枠（`src/core/modes.ts` の MINIGAMES。セレクト画面の 絵には 枠が ある）に 入れる。ほかの ゲームは さわらない
- 麻雀の 計算は `src/core/mahjong/`（Phaser なし・テストつき・乱数は 種から 再現）
  - `tiles` 牌・山・王牌／`hand` 手牌・鳴き・テンパイ・待ち／`yaku` 役／`score` 符・翻・点数／`round` 1局の 流れ（ツモ・打牌・鳴き・リーチ・ロン・フリテン・流局）／`ai` CPU
- RPG の 計算は 別に `src/core/mahjong/rpg/`（麻雀の 点数を 受けとって ダメージに する。アイテムも ここで 独立させる）
- 画面は 横画面・全画面（MONZ RUMBLE と 同じ やり方）
- 保存は `monz:life` に 足す（古い データも 読める ように `migrateLife`）

## 3. 作る順番（Claude の案。各段は 企画者の OK の あとに 進む）
1. **麻雀の 計算**：牌・山・配牌・ツモ・打牌・鳴き・リーチ・役（全部）・符・点数・フリテン・流局。テストを たくさん 書いて 正しさを 確かめる（画面なし）

5. **道具屋・アイテム**
6. **演出**（満貫以上・役満・アイテム）と タイトル・ステージえらび
