## 2. ゲームの流れ（実装済み）

1. **タイトル**（`TitleScene`）→ はじめてなら質問へ、2回目からはお世話画面へ
2. **質問**（`QuestionScene`）5問【仮の質問】→ 誕生
3. **誕生**（`BirthScene`）ドラゴンが卵を運ぶ → BUNKが生まれる → **名前をつける**
4. **部屋を選ぶ**（`RoomSelectScene`、`mode: 'first'`）「○○をどこで育てる？」STREET / POP / CYBER の3つから【確定】
5. **お世話画面**（`HomeScene`）ここが中心

## 3. お世話画面（`HomeScene` / `HomeFurniture`）

- 上：名前・レベル・経験値ゲージ・**今の気分のひとこと**（例「おなか すいた…」）・コイン・「アイテム」・「もようがえ」ボタン
- 下のボタン：ごはん／ミニゲーム／ステータス／バトル（SOON）／ショップ／設定
- 右上の小さいボタンは**開発用**（最初から・誕生をもう一度・+1000コイン・6時間すすめる・部屋を選び直す）。**公開前に外す**。「最初から」「誕生をもう一度」はお世話のデータを全部消す（誕生をもう一度は最初の質問の答えだけ残す）【確定 2026-10-22】
- BUNKは床を自分で歩き回る（歩く・見回す・座る・寝る・伸び・あくび・ねだる・泣く など）。家具はよけて歩く
- 指でなでる・タップできる
- 床を指で押さえている間、BUNKが指を追いかけてくる（家具はよけて歩く）。眠っている・機嫌が悪い・お腹がすいているときは来ない【確定 2026-10-22】

### お世話の数字【確定】（`src/core/needs.ts` `src/core/stats.ts`）
| 項目 | 決まり |
|---|---|
| お腹のゲージ（見えない） | 最大10。1時間に1へる。ごはんで2もどる。生まれたときは5 |
| なでるのゲージ（見えない） | 最大10。1時間に1へる。なでると1もどる。生まれたときは5 |
| ごはん | お腹がMAX(10)のときは食べずに怒る（怒った顔＋「プイ」の音、文字なし）。経験値15（1日50まで） |
| なでる | ゲージがMAXでなければ経験値4（回数の上限なし）。MAXのときになでると怒る。機嫌が悪いとときどき嫌がる |
| 愛 | 最初0（2026-10-22 変更。前は20）・最大100。ごはん+0.5（お腹8以下のとき）・なでる+0.2（なでる9以下のとき）。ゲージが0のまま2時間で−0.1。画面には整数で出す |
| 様子 | お腹3以下→お腹すいた姿が多い／なでる3以下→泣く姿が多い |
| レベル | 次のレベルまで 110＋(レベル−1)×15。レベルアップでコイン（レベル×10）、自動成長＋自由ポイント |
| ステータス | HP・パワー・タフネス・スピード・テクニック・愛。最大150（愛は100）。振り直し不可 |

## 5. ショップ・アイテム・家具

- **ショップ**（`ShopScene`、`mode: 'shop'`）：タブ「家具」「引越し券」。家具は STREET / POP / CYBER（VIP開放後は VIP も）で切りかえ。コスチュームは後回し【確定】
- **アイテムボックス**（同じ画面、`mode: 'box'`）：タブ「家具」「その他」。家具→「部屋に置く？」、引越し券→引越し先を選ぶ
- **引越し券**：10,000コイン【仮】。1枚で1回引っ越せる。使うとなくなる。今の部屋は選べない。置いてある家具はアイテムボックスにもどる。確認文「注意：引越し券を1枚使います。使ったら元にもどせません。…」【確定】
- **VIPの家具**：はじめてVIP ROOMに引っ越すと開放【確定】。値段はふつうの2倍【仮】
- 家具は4シリーズ×8種類（ベッド・ソファ・テーブル・カーペット・テレビ・照明・植物・おもちゃ。テレビ・植物は2026-10-22追加）。値段【仮】：ベッド500・ソファ400・テーブル250・カーペット200・テレビ400・照明300・植物150・おもちゃ150。同じ物を何個でも買える【確定】
- どの部屋にも、どのシリーズの家具も置ける【確定】

### もようがえ（`src/scenes/HomeFurniture.ts`、決まりは `src/core/roomLayout.ts`）
- 指で動かす・「向き」（横・横の反転・縦・縦の反転の4つ。縦は縦向きの絵がある家具だけ。置けない場所でも向きは変えられる→赤くなり、動かして置ける所へ。置けないまま終えると、さいごに置けていた形にもどる）・「しまう」・「おわる」
- 「大きさ」：カーペット（小・中・大）とテーブル（ふつう・大きめ＝1.2倍【仮】）。テーブルは置けない大きさでも変えられる（赤くなる。向きと同じ）
- 家具は床の上だけ。家具どうしは重ねられない。床がまん中で2つに分かれる置き方はできない（歩ける床のいちばん広い所が7割【仮】残ればよい。家具と壁・家具どうしの小さなすきまはあってよい。BUNKがすきまに閉じこめられたら広い所へ移す）。家具が床で占める奥行きは浅め【仮】
- 奥に置くほど小さく見える（BUNKより ひかえめ）。家具の絵は床の線に合わせて少しだけかたむける（形はあまり変えない）
- BUNKが家具の後ろを通っても家具は透けない（2026-10-22 変更）
- **カーペット**：床と同じあつかい（BUNK・家具の下に敷ける。家具をのせられる）。カーペットどうしは重ねない。「大きさ」で 小・中・大【確定】（倍率【仮】1・1.35・2.2）。床からはみ出さない。奥では入る大きさまで小さくなる（選んだ大きさの7割まで【仮】）
- 置いた場所・向き・大きさは保存される

### 家具の絵（`design/furniture/` → `public/assets/furniture/`）
- 白い背景の絵を `python3 design/furniture/make_furniture.py` で切り抜く。横向き `<シリーズ>_<種類>.png`、縦向き `<シリーズ>_<種類>_turn.png`
- 絵を足したら `src/core/furniture.ts` の `FURNITURE_ART_READY`（横向き）と `FURNITURE_TURN_ART`（縦向き・縦÷横）に足す
- 届いている：STREET ベッド・ソファ・テーブル・カーペット（横・縦とも）、テレビ（横・縦とも）、照明・植物・おもちゃ（横だけ）。STREETは全部そろった
- 届いている（POP）：ベッド（横・縦）、ソファ（横・縦）、テーブル（横・縦）、カーペット（横・縦）、テレビ（横・縦）、照明、植物、おもちゃ（全部そろった）
- 届いている（CYBER）：ベッド（横・縦）、ソファ（横・縦）、テーブル（横・縦）、テレビ（横・縦）
- まだ：CYBER の残り、VIP の全部（絵がない家具は【仮】の色つきの箱）
- 使わなくなった絵は `design/furniture/unused/`

## 10. 開発のやり方（いつもの手順）

- ブランチ：`claude/monz-game-development-pztk8y` に push（main には企画者の許可が出るまで入れない）
- 確かめる：`npm run typecheck` と `npm test`（今 104 テスト）
- 画面で確かめる：`npx vite --port 5199` を動かして、Playwright（`/opt/pw-browsers/chromium`）で iPhone の大きさ（390×693）の画面を撮る
- 企画者に見せる：`rm -rf dist && npm run build && python3 -I tools/build_preview.py <出力.html>` で確認用ページを作り、Artifact で公開（https://claude.ai/artifact/9qauCQZ9xmdERAFrzwkeLh を同じ場所で更新）。ページが重くなったら絵を軽くしてよい（見た目の大きさは変えない。企画者 2026-10-22: 前に15MBで開かなかったのは勘ちがいだったかも）
- 決まったことは `docs/VISION.md`（全体）か `docs/ROOM_PLAN.md`（部屋・家具）に日付つきで足す。このファイルの表も合わせて直す
