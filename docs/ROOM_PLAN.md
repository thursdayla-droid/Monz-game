## 4. 作り方の計画

### ① 部屋の置きかえ
- 部屋の名前を「ストリート・ポップ・近未来」の3つに変える
- 部屋ごとに「床の歩ける範囲」「壁に飾れる範囲」を、届いた絵に合わせて決める
- 今の部屋の保存データは、決めてもらった方法で新しい部屋に引き継ぐ（データの版を1つ上げて、1回だけ変換する。ほかのデータには触らない）

### ② 家具のデータと家具ショップ
- 家具の一覧表を1か所にまとめる。家具を増やすときは、表に1行足して絵を入れるだけにする
- 1つの家具が持つ情報：名前・種類（ベッド・ソファなど）・値段【未確定】・絵・床に置く／壁に飾る／テーブルの上に置く・床の上で占める大きさ・左右反転できるか・MONZがそこでする行動
- ショップのボタンを使えるようにする。種類ごとに並べ、コインで買う。買った物は「しまってある家具」に入る

### ③ 家具を自由に置く
- 部屋に「もようがえ」ボタンを出す（場所は相談）。押している間はMONZは止まる
- 家具をタップで選ぶ → 指で動かす → 手を離すと置く。置いた後もいつでも動かせる
- 選んでいる家具には「しまう」「向きを変える」ボタンを出す
- 置けない場所（床の外・ほかの家具に重なる・壁の家具が床にある 等）では赤く表示し、離すと元の場所に戻る
- 重なりの判定は「床の上で占める範囲」で行う（絵の見た目どうしは少し重なってよい。奥の物が手前の物の後ろに見えるのは自然なので）
- 前後の重なりは、足元（床に接する所）が手前にある物ほど前に描く。MONZも同じ決まりで並べる
- 背の高い家具の後ろにMONZが入ったら、その家具を少し透かしてMONZが見えるようにする（案）
- 置いた場所は保存し、アプリを閉じても残る

**回転の案**
- 案A（おすすめ）：左右反転だけ。絵1枚で済む。ベッド・ソファ・テーブルなど多くの家具は自然に見える
- 案B：家具ごとに「正面」「横向き」などの絵を別に用意し、ある物だけ切りかえる。絵の数が増える
- 案C：自由な角度で回す。2Dの絵では不自然になるので、おすすめしない

### ④ MONZが家具をよけて歩く
- 床を細かいマス目に分け、家具が占めるマスを通れないようにして、通れる道を探して歩く
- 家具でふさがって行けない場所は、行き先に選ばない

### ⑤ 家具に合った行動
- 行動は家具の一覧表に書く。例：ベッド＝「近くまで歩く → 寝る → 起きる」、ソファ＝「座る」、おもちゃ＝「遊ぶ」
- 今の「次の行動を気まぐれに選ぶ」しくみに「家具を使う」を加える。選ばれやすさは家具ごとに決め、使ったばかりの家具は選びにくくする。眠いときはベッドが選ばれやすい、など今のお腹・眠さとつなげる
- 家具を置いても、すぐ・毎回使うわけではない
- 絵がない行動は、絵が届くまで行動の一覧に入れない（代用しない）
