## 1. 考え方

- **技 = 型 ＋ 属性 ＋ 強さ**。例：「弾」＋「炎」＝ 火の玉、「弾」＋「水」＝ 水の玉。
- 型ごとに、動き（ためる・撃つ・突進する）と光の見せ方を1回だけ作る。属性で色と飛び散るもの（火の粉・しぶき・葉っぱなど）が変わる。
- 動きは30体それぞれではなく、**体の形**ごとに作る（丸い体・四つ足・二本足・飛ぶ・長い体 など数種類）。3Dモデルが届いたら、どの体の形かを決めるだけで動く。
- 数字（威力・待ち時間など）は、**型と強さの段階**から計算で決める。企画者・ChatGPT は数字を書かなくてよい。
- 30体を総当たりで自動対戦させ、勝ちすぎ・負けすぎを見つけるテストを作る。

## 2. 技の型（案・14種類）

| 型 | どんな技か | よけ方・弱点 | 今の試作 |
|---|---|---|---|
| 突進 | まっすぐ体当たりして吹っ飛ばす | 横によける。外すとすきが大きい | ダッシュアタック |
| 弾 | 1発の弾を撃つ | 横によける。弾どうしはぶつかって消える | ファイアショット |
| 連射 | 小さい弾を3〜5発つづけて撃つ | 1発は弱い。全部当たると強い | ― |
| ビーム | ためてから太い光線 | ため中に横へ逃げる。ためが長い | ライトニングビーム |
| 衝撃波 | 跳んで地面をたたき、輪が広がる | ジャンプでよける。近い相手にだけ | グラウンドブレイク |
| 落下 | 相手の足もとに印 → 少しあとに上から落ちる（雷・岩など） | 印から出る | ― |
| 設置 | 地面に置く（火の床・毒の沼・ツタ）。ふむとダメージ・遅くなる | 近づかない | ― |
| 連続攻撃 | 近づいて すばやく何回も打つ | 近くでしか当たらない | ― |
| 回転 | 体ごと回って、まわり全部を攻撃 | 離れる | ― |
| 守り | 前に壁を出して、少しのあいだ弾や攻撃を止める | 横や後ろから | ― |
| 回復 | HPを少し回復 | 使っているあいだ動けない | ― |
| 強化 | 少しのあいだ 自分の攻撃や速さが上がる | ― | ― |
| 弱体 | 相手を遅くする・攻撃を下げる | 当たらなければ効かない | ― |
| 吸収 | 当てたダメージの一部で回復 | 弱め | ― |

- **大技**（第2進化 Lv.60 の技）：どの型でも「大技」の印を付けると、ためが長く・威力が大きく・演出が派手（カメラが寄る・画面が光る）になる。
- **追加効果**（なし・やけど・まひ・こおり・どく・ねむり・ふらつき など）：付けられる型を決めておく。【未確定】

## 3. 強さの段階（数字は計算で決める）

| 段階 | めやす |
|---|---|
| 弱 | 待ち時間が短い。気軽に使える |
| 中 | ふつう |
| 強 | 待ち時間が長い。当たると大きい |
| 大技 | 第2進化の技。1試合に何回も使えない |

- 【仮】威力 ×（当たりやすさ）÷ 待ち時間 が、型・段階ごとに だいたい同じになるように計算する（当てやすい技は弱く、当てにくい技は強く）。

## 4. 体の形（案）

| 体の形 | 例 | 動き |
|---|---|---|
| 丸い体 | 今の仮のモンスター | 跳ねて動く・体ごとぶつかる |
| 四つ足 | けもの | 走る・飛びかかる・かみつく |
| 二本足 | 立って歩く | 手で打つ・けりも使う |
| 飛ぶ | 鳥・こうもり | 空中にいることが多い・上から攻撃 |
| 長い体 | へび・りゅう | くねって動く・巻きつく・しっぽ |

## 5. ChatGPT に作ってもらう表（2つ）

表は CSV（カンマ区切り）の形にしてもらう。そのままゲームに読みこめる。見本：`docs/templates/`。

### 表1：種族の表（`monz_species.csv`）— 30行（10種族×3形態）

- 2026-11-01：入れ物を作った。表は `data/monz_species.csv`（BUNK と MOFU・ZIPP・PUNI・KLAK の名前だけ入っている。ほかは「（未定）」、まだ決まっていない5種族は MONZ6〜MONZ10）→ `python3 -I tools/species_csv.py` → `src/core/rosterData.ts`。3Dモデルは `src/core/roster.ts` の `MODEL_FILES` に足す（ないと3Dバトルで仮のモンスター）

| 列 | 書くこと |
|---|---|

| 名前 | その形態の名前 |
| 体の形 | 丸い体 / 四つ足 / 二本足 / 飛ぶ / 長い体 |
| 属性 | 炎 / 水 / 自然 / 雷 / 光 / 闇 / 無 |

| メモ | 戦い方のイメージ（自由に） |

### 表2：技の表（`monz_techs.csv`）— 1種族 8〜10個くらい

| 列 | 書くこと |
|---|---|
| 種族 | BUNK など |
| 技名 | 既存の作品の技名と同じにしない |
| 型 | 2. の14種類から1つ |
| 属性 | 炎 / 水 / 自然 / 雷 / 光 / 闇 / 無 |
| 強さ | 弱 / 中 / 強 / 大技 |
| 覚えるレベル | 数字（Lv.1 の技は2つ） |
| 条件 | なし / パワー寄り / タフネス寄り / スピード寄り / テクニック寄り / HP寄り / 第1進化 / 第2進化 |
| 追加効果 | なし / やけど / まひ / こおり / どく / ねむり / ふらつき / 遅くする / 攻撃ダウン |
| 見た目のメモ | どんな光・動きか（自由に） |

- **条件の意味**：「パワー寄り」= その時にパワーが（種族のふつうより）高く育っていると覚える。同じ種族でも育て方で覚える技が変わる。
- 【提案】1種族のめやす：Lv.1 の技2つ ＋ ふつうに覚える技2つ ＋ 育て方で変わる技 2〜4つ（パワー寄り・スピード寄り…）＋ 第1進化の技1つ ＋ 第2進化の大技1つ。
- 同じ技を ほかの種族も覚えてよい（そのときは同じ技名で書く）。
