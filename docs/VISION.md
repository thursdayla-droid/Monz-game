## 愛とお腹（2026-10-21 企画者決定）

- お腹のゲージ（プレイヤーには見せない）：最大10、1時間に1へる。ごはんで2もどる。
- なでるのゲージ（見せない）：最大10、1時間に1へる。なでると1もどる。
- 愛：ごはん1回で +0.5。ゲージが8以下（2目もり ぜんぶ食べられる）のときだけ増える。なでると +0.2（なでるのゲージが9以下のときだけ。2026-10-21）。1日の上限はなし。画面には整数（小数点以下は見せない）で出す。
- 様子（2026-10-21）：お腹のゲージが3以下 → お腹すいた姿（ねだる）がとても多くなる。なでるのゲージが3以下 → 泣いている姿がとても多くなる。
- 愛がへる：お腹のゲージが0のまま2時間で −0.1。なでるのゲージも同じ（両方0なら2時間で −0.2）。0より下にはならない。アプリを閉じている間も数える（最大7日）。
- ごはんを断る：お腹のゲージがMAX（10）のときにごはんをあげると、食べずに怒る（文字は出さない。怒った顔と「プイ」の音）。経験値・愛は増えない。
