## モード：ストーリーモード と バトルモード（2026-11-03 企画者）
- バトルメニューの「バトル」→ モードえらび（`src/scenes/RumbleScenes.ts`。見た目は仮。さいごに企画者が背景・セレクト画面の絵を作る）
- **バトルモード**：CPU の強さを えらぶ（`src/core/rumble.ts` の CPU_LEVELS【仮】）：よわい（自分より Lv−5・うまさ★1）／ふつう（同じ・★2）／つよい（+3・★3）／とてもつよい（+6・★4）／さいきょう（+10・★5）。うまさ＝よけ方・ねらい・守りのうまさ
- **ストーリーモード**：すごろくのマス20（5マスずつ じぐざぐ）。光っている次のマスをさわると、コマが1マス進んで 一枚絵と話 → バトル。勝つとクリア（保存）→ 次のマスが光る。クリアしたマスは何度でも遊べる。全部クリアで「ストーリー クリア！」
  - 敵【仮】：レベル 1 → 約65、さいごのボスは Lv.70・うまさ★5。うまさは5マスごとに上がる。5・10・15マスめは中ボス、20マスめがさいごのボス（ボスは HP 1.5倍）
  - 話の文・一枚絵は企画者が作る（今は「ここに話が入ります」と仮の文）。報酬は まだ決まっていないので無し
  - 保存：`LifeData.rumble.cleared`（クリアした いちばん先のマス。古いデータには無い＝0）
- 3Dバトルの確認用ページは、モードえらびから始まる（開発用の「確認用」ボタンはバトルの中にある）

## MOFU の技（2026-11-03 企画者「技お願いします」「モフの攻撃はちょっこりタックル」）
- 技リスト案の MOFU 17技を、技の表（`data/monz_techs.csv`）に入れた。数字は技リスト案のまま【案】
- 新しい型：回復（最大HPの18%×強さ・0.8秒動けない・1試合の回復は最大HPの80%まで）／強化（20%×強さ・6秒。もりの息吹 = 受けるダメージが減る。ほかの種族の強化は技ごとに 攻撃・守り・速さ）／吸収（弾のように飛び、当てたダメージの半分を回復）
- 千花天幕（設置・大技）は自分の足もとに花の輪：中にいる間 1秒ごとに最大HPの3%回復・受けるダメージ0.6倍
- 設置の追加効果（ねむりの綿雨 = ねむり）・弱体の追加効果（花嵐のゆりかご = ねむり）が効くようにした
- 通常攻撃：MOFU（Lv.1・腕がない）は ちょっこりタックル（1発ごとに体ごと前へ小さく ぶつかる・少し前へ進む）。MOFUR・MOFUGARD は腕でパンチ。進化したパンチの火の粉・火の玉は BUNK だけ
- 2026-11-03 企画者「通常攻撃はツルの鞭みたいな中距離射程の攻撃とかにしよう」→ MOFU・MOFUR・MOFUGARD の通常攻撃は ツルのムチ（タックルから変更）：とどく長さ 3.4 / 3.8 / 4.2（BUNK のパンチは 1.9〜2.5）・2 / 3 / 4連・合計の威力 0.85 / 1.35 / 1.7倍（BUNK より少し低い）【仮】。体の前（手があれば手）から緑のツルが しなってのびる・ひゅっ ぴしっ の音。2026-11-03 企画者「見えにくい」→ ツルを太く（こい緑のふち＋明るいまん中）・根もとから先へ のびていく・0.38秒残る・ツルにそって葉っぱ・先で光る。2026-11-03 企画者「エフェクトしょぼい」→ 大きく横から振りぬく（残像のツル2本）・先に緑の斬撃の弧・当たると葉っぱが くるくる回って はじけ、緑の光の輪（さいごの1発は大きく）。ムチの当たりでは ふつうの白い煙・黄色い輪は出さない
- 2026-11-03 企画者「通常攻撃長くて強いから モフは単発、モファーは2コンボ、モフガルドは3コンボ」→ ツルのムチは 1 / 2 / 3発・合計の威力 0.45 / 1.0 / 1.44倍【仮】（とどく長さは そのまま）
- 自動でえらぶ4つは、攻撃の技を2つ以上のこす（守りと回復ばかりにならないように）
- ねむり 2.5秒 → 2.0秒。ねむっている相手を起こした攻撃（起きてすぐ0.3秒の間も）では ふっとばない（ねむり＋ふっとびで3秒以上 動けなくならないように）
- ためし（MOFU 対 BUNK・オートどうし）：Lv.1 50% / Lv.10 50% / Lv.30 42% / Lv.60 42% / Lv.70 38%（MOFU の勝つ割合）。いちばん長く動けない時間 2.7秒（3秒より短い）
- 見た目：回復 = 緑と白の光がのぼる・光の輪（大技は光の柱）／強化 = 色の光の輪・強化中は体のまわりに色の粒／吸収 = 当てた相手から光の粒がもどる／千花天幕 = 花と光の根の輪・花びらがのぼる。音も型ごとに作った【仮】

## BUNKER・BUNKLORD の3Dモデルを差しかえ（2026-11-03 企画者）
- 企画者の新しい Tripo モデル（骨入り・78本の人の形の骨）に差しかえた。元は `design/battle3d/bunker_tripo_rigged_original.glb`・`bunklord_tripo_rigged_original.glb`。前のモデル（BUNKLORD は こちらで骨を直したもの）は `unused/battle3d/*_v1.glb`

- 軽くしたあと：BUNKER 1.26MB・BUNKLORD 1.42MB（前は 1.34・1.80）

## MOFU の技の見た目（2026-11-03 企画者「モフっぽいのに変えてほしい」）
- MOFU の技は、岩・土けむり・オレンジの火花・紫の光を使わず、綿毛（ふわふわの白いかたまり）・花びら（ピンクと白）・やわらかい風にした
- 突進（ふわっとダッシュ）= うしろに綿毛の帯と花びら／回転（ふわころ）= 白とピンクの輪・綿毛が舞う／弾（わたげだま・わたげちらし）= ゆらゆら回る綿毛の玉・綿毛をこぼす／衝撃波（ふわりの風・超膨張インパクト）= 白い風の輪・綿毛と花びら（大技はピンクの光の柱）／落下（もふどっかん など）= 跳ぶ時と着地で綿毛と花びらが ぶわっと／守り（もふガード など）= 綿雲のドーム／弱体（花嵐のゆりかご）= ピンクの輪と花びらのうず／設置（ねむりの綿雨）= 綿雲のじゅうたん・上に雲・綿毛の雨／当たった時 = 綿毛と花びらが はじける

## 1. ゲームのコンセプト

### 1. 基本の方針

- 2D横から見たアクションバトル。操作の気持ちよさは、64のスマブラに近いものを目指す（キャラクターや見た目はまねしない）。
- 基本は1対1。
- HPは全MONZ 100で固定。
- ストックは2。HPが0になると1ストック失う。ステージの外に落ちても1ストック失う。
- HPが減るほど、攻撃で吹っ飛びやすくなる。
- 復活するとHP100にもどる。
- 相手のストックを0にすると勝ち。
- 育成のステータス（HP・パワー・タフ・スピード・テクニック・愛）は、このバトルの攻撃力・防御力・移動の速さなどに**直接は反映しない**。
- キャラクターごとのちがいは、MONZ固有の基本性能・決まったアクション・覚えた技で出す。

### 2. 操作

#### Aボタン：通常攻撃（固定）
- MONZごとに決まった通常攻撃。付け替えはできない。
  - 通常A：ニュートラル攻撃
  - 横＋A：横攻撃
  - 上＋A：上攻撃
  - 下＋A：下攻撃
- 空中攻撃も、MONZごとに決まったアクション。

#### Bボタン：必殺技（付け替えできる）
- 4つの枠：通常B／横＋B／上＋B／下＋B。
- レベルアップや進化で新しい技が増える。覚えた技は技の一覧に残り、バトルの前に自由に付け替えられる。
- 技にはそれぞれ入力の向きが決まっていて、その向きの枠にだけ付けられる（基本）。
- 上Bには、ステージにもどるための技（復帰技）を付けられる。

#### そのほか
- 左スティック：移動・向きの入力
- ジャンプボタン：ジャンプ（空中でもう1回。基本は2段ジャンプ）
- シールドボタン：防御
- 上B：主な復帰アクション
- スマホで操作しやすい、シンプルなボタン配置を目指す。

### 3. 初期MONZと進化

- 初期MONZは全部で10匹。
- **分岐進化する5系統**：基本の形 → Lv.30で育て方の傾向により2種類に分かれる → Lv.60でそれぞれ最終進化。1系統5形態、合計25形態。進化先はプレイヤーが選ばず、育てたステータスの傾向などで自動に決まる。
- **決まった進化をする5系統**：基本の形 → Lv.30 → Lv.60。1系統3形態、合計15形態。
- 合計40形態。

### 4. レベルと技を覚える流れ

- 最大レベルは100が候補。
- Lv.1〜29：基本の技を覚える
- Lv.30：1回目の進化＋進化した姿だけの技

- Lv.60：最終進化＋最終進化だけの技

- 覚えるレベル・技の数・最大Lv.100にするかは、これから調整。

- 分岐進化で覚える専用の技は、その進化ルートだけのもの。

### 5. 強くなりすぎない工夫

- レベルが高くても、育成ステータスで戦う力が直接上がることはない。
- 進化やレベルアップで増えるのは、主に「使える技の選択肢」。
- 強い技には弱点をつける（出るのが遅い・攻撃のあとにすきがある・続けて使えない時間がある・届く距離が短い など）。
- 低いレベルで覚える技にも長所を残す（出るのが速い・つなげやすい など）。
- 進化後は少し強い技を使えるが、低いレベルのMONZでも操作のうまさで勝てるバランスを目指す。
