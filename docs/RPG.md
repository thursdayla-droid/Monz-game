# MONZ 擬人化RPG（新しい モード・検討段階）

> 2026-11-26 企画者：MONZ を 擬人化して 操作する RPG（ラグナロクオンラインのような 懐かしい MMORPG の 世界観と 操作感。王道ファンタジー ＋ MONZ の ストリート文化）。
> **まだ 本格的な 実装は しない。** 冒険モード・MONZ RUMBLE は 変えない（独立した 新しい モード）。既存作品の キャラ・素材は 使わず すべて オリジナル。

## 企画者の 構想（2026-11-26）
- 見た目：3D マップ ＋ キャラ（下の A か B）。斜め上から 見下ろす。スマホ 横画面。キャラは 3〜4頭身。技の 光は 今風で 迫力
- 擬人化：元の MONZ の 色・耳・角・髪型・模様・性格を 残す。ストリートファッション ＋ ファンタジー装備。種族ごとに 見た目と 戦い方。装備で 見た目が 変わる しくみも 検討
- 動き：8方向の 移動・待機・歩く・通常攻撃・技・ダメージ・戦闘不能
- マップ：街・草原・森・洞窟・ダンジョン（3D）。建物・木・岩・宝箱。街で NPC と 話す・ショップ・装備を 買う
- 将来：職業・レベル・技を 覚える・装備集め・レアドロップ・クエスト・ボス・オンライン協力・プレイヤーどうしの 交流
- 進め方：A と B を 比べる → BUNK の 擬人化 1体と 小さな テストマップで 試作 → 画面を 見て 方式を 決める

## 方式の 比較（2026-11-26 Claude。企画者の 判断待ち【未確定】）
- A：3D マップ ＋ 2D ドットの キャラ
- B：3D マップ ＋ 3D の 擬人化キャラ
- C（Claude の 追加案）：B の 3D モデルから、ゲームの 外で 8方向の ドット絵を 自動で 写して A の 見た目に する

## 前の 決定との 関係
- 同じ日の「冒険の 中で 擬人化・ロール 6つ」（`docs/ADVENTURE.md`）は、この 新しい モードの 話に 移す（冒険は 今の まま）。ロールの 割り当て（剣士 = ZIPP・RIOT・CROWNIE など）は こちらの 職業の 案として のこす

## 2026-11-26 試作の 進め方（企画者 OK）
- BUNK 1体で B（3D）と C（3D から 8方向の ドット絵を 自動で 撮る）を 同じ テストマップで 見比べる。A は 絵 1枚で 見た目だけ 比べる
- まず 企画者が ChatGPT で BUNK の 擬人化の 絵（三面図・3D 用の 正面）を 作る → 3D モデル。テストマップは 路地裏の 床・壁・置き物を 使う
- 2026-11-26 BUNK の 擬人化の 三面図が とどいた（`design/rpg/bunk/turnaround.png`。オレンジと 紫の 髪・丸い 紫の 耳・ピンクの とさか・眠そうな 赤い 目・ギザ歯・ばんそうこう・紫の 大きな こぶし。パーカー＋ジャケット・革ベルト・×の 腰布・スニーカー）
- 2026-11-26 BUNK の 擬人化 3D モデルが とどいた（`design/rpg/bunk/bunk_rpg_tripo_original.glb`。198万面・23MB・骨 78本〔今までの BUNK と 同じ 名前〕・動きの データ なし）→ 軽くした もの `public/assets/rpg/bunk_rpg.glb`（約3万面・0.6MB。手順は `design/battle3d/README.md` と 同じ gltf-transform optimize --simplify-ratio 0.015）
- 試作の ページ（`--rpg`）: 冒険の 路地裏を 借りて、BUNK 擬人化で 歩く・攻撃する（動きは 今の BUNK の 骨の 動き）。カメラは 近め（キャラを 大きく。2026-11-26 企画者「近すぎる」→ 冒険の 17 と 試作 8.5 の 間の 12 → 同じ日「もう少し 遠くても いい」→ 14.5）【仮】。「見た目」ボタンで B（3D）と C（体を 小さな 絵に 写して ドットに 見せる・8方向）を 切りかえる
- 2026-11-26 技の 演出の 絵は 企画者が ChatGPT で 作る（1枚ずつの 止まった 絵。動きは プログラム）。全部で 約30枚（どの 技でも 使う 8・属性ごと 7×3・ロールの 道具 4）。まず BUNK の 試作用に 12枚（共通 8＋炎・雷・光・闇の 爆発）。光る 絵は 背景を 真っ黒に（光を 足して 重ねる ため）
- 2026-11-26 演出の 絵 12枚が とどいた（`design/rpg/fx/` → `public/assets/rpg/fx/fx_*.webp`）。試作で BUNK（剣闘士）の 技の 演出を 作った: 技の 名前を 頭の 上に さけぶ・ため中は 足もとに 魔法陣（攻撃 = とがった 陣・回復や 守り = 花の 陣）・形ごとに 斬撃／衝撃波／光の 柱／煙・当たると 属性の 爆発（炎・雷・光・闇 は 絵、ほかは 火花を 色で 染める）・通常攻撃は 斬撃の 絵【仮】。技の 名前・属性・効果は MONZ の まま（形だけ ロールの 動き）。武器の 3D は まだ
- 2026-11-26 企画者「技名は 叫ばなくて 良い」→ 技の 名前は 出さない
- 2026-11-26 企画者「通常攻撃 剣闘士に しては 広すぎる」「擬人化の 方は 姿は 変わらないけど、進化したら 攻撃の 長さが 少し 広がる 感じで いい」→ 剣闘士の 通常攻撃は 長さ 1.8・左右 約30度（前の 半分くらいの 広さ）。第2形態（Lv30）で +0.3・第3形態（Lv60）で +0.6【仮】。擬人化の 姿は 進化しても 同じ
- 2026-11-26 企画者「歩き方 じゃっかん 違和感」→ 擬人化の 体は 人の 歩き方に（前の けものの BUNK の ぴょこぴょこ・体の つぶれを やめた）。腕を 体の 横に 下ろす・足を 交互に 前後（振り出す 足は ひざを 曲げる）・腕は 足と 反対に 振る・腰と 肩を 少し ひねる。歩く 調子は 速さに あわせる（足が すべって 見えない ように）【仮】
