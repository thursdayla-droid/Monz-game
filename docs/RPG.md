# MONZ 擬人化RPG（新しい モード・検討段階）

> 2026-11-26 企画者：MONZ を 擬人化して 操作する RPG（ラグナロクオンラインのような 懐かしい MMORPG の 世界観と 操作感。王道ファンタジー ＋ MONZ の ストリート文化）。
> **まだ 本格的な 実装は しない。** 冒険モード・MONZ RUMBLE は 変えない（独立した 新しい モード）。既存作品の キャラ・素材は 使わず すべて オリジナル。

## 企画者の 構想（2026-11-26）
- 見た目：3D マップ ＋ キャラ（下の A か B）。斜め上から 見下ろす。スマホ 横画面。キャラは 3〜4頭身。技の 光は 今風で 迫力
- 擬人化：元の MONZ の 色・耳・角・髪型・模様・性格を 残す。ストリートファッション ＋ ファンタジー装備。種族ごとに 見た目と 戦い方。装備で 見た目が 変わる しくみも 検討
- 動き：8方向の 移動・待機・歩く・通常攻撃・技・ダメージ・戦闘不能
- マップ：街・草原・森・洞窟・ダンジョン（3D）。建物・木・岩・宝箱。街で NPC と 話す・ショップ・装備を 買う
- 将来：職業・レベル・技を 覚える・装備集め・レアドロップ・クエスト・ボス・オンライン協力・プレイヤーどうしの 交流
- 進め方：A と B を 比べる → BUNK の 擬人化 1体と 小さな テストマップで 試作 → 画面を 見て 方式を 決める

## 方式の 比較（2026-11-26 Claude。企画者の 判断待ち【未確定】）

- B：3D マップ ＋ 3D の 擬人化キャラ
