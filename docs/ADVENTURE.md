# 冒険（ADVENTURE）

2026-11-07 企画者が はじめた。お世話画面の下の「冒険」から 入る（今は じゅんび中）。
今 育てている MONZ で、上から 見下ろす ダンジョンを 進み、モンスターを 倒して ボスを 倒す。
見本の 雰囲気は 上から見る アクションRPG（企画者の イメージ）。既存の 作品の キャラ・マップ・絵は 使わない。

## 決まったこと（企画者 2026-11-07）
- 今 育てている MONZ を 使う。ステータス（HP・パワー・タフネス・スピード・テクニック）と レベルは そのまま 冒険に 反映。
- 技の 名前は MONZ RUMBLE の 技を そのまま 使う。エフェクト（見た目）は 冒険用に 変える。
- 型ごとの 役：
  - パワー型 ＝ 攻撃（強い 一撃・まわりを なぎはらう）
  - タフネス型 ＝ 回復（自分を 回復・守り。仲間が できたら 仲間も）
  - スピード型 ＝ 速い 攻撃（すばやい 連続攻撃・速い 移動）
  - テクニック型 ＝ 弱らせる（遠くからの 攻撃・やけど・どく・ねむり）
- モブや ボスを 倒すと 経験値と コイン。
- 冒険中に 使える アイテムや 装備を 落とす（ドロップ）。
- 装備は D・C・B・A・S の ランク。S が 強くて 出にくい。レベルが 低くても いい 装備で クリアできることも ある。
- はじめは 自分の MONZ 1体で 行く（仲間は あとで 足せるように 作っておく）。
- 見た目は 3D（MONZ RUMBLE の モデルを そのまま 使い、カメラを ななめ上から）。スマホは 横向き。
- ダンジョンは 入るたびに 形が 変わる（部屋と 通路を 自動で 作る）。何階か 進むと ボス。

## 【仮】Claude の 案（企画者が 決めるまで）
- 操作：左で 移動（スティック）、右に 通常攻撃と 技4つ（MONZ RUMBLE と 同じ ならび）。技は お世話の ステータスで セットした 4つ。
- 1回の 冒険：3階 ＋ ボスの 階。階の 中の モンスターを 倒すと 次の 階への 階段が 開く。
- 装備の 場所：3つ（ツメ＝攻撃が 上がる／ヨロイ＝受ける ダメージが 減る／オマモリ＝特別な 力）。
- ランクの 出やすさ：D 50%・C 30%・B 14%・A 5%・S 1%。ボスは 少し 出やすい。
- アイテム：回復の 実（HP 回復）・技の 待ち時間を 0 に する など。冒険の 中だけで 使える。
- 負けた時：経験値・コインは もらえる。その 冒険で 拾った 物は なくなる（つけている 装備は 残る）。

## 作る 順番（各段階は 企画者の OK の あとで 次へ）
1. 試作：1階だけ。部屋と 通路を 自動で 作る、MONZ を 動かす、通常攻撃、モブ 1種類。倒したら おわり。
2. 技（型ごとの エフェクト）・モブを 数種類・ボス。
3. ドロップ（アイテム・装備 D〜S）、装備の 画面、保存。
4. 階を ふやす・強さと ごほうびの バランス。

## オンライン（企画者 2026-11-07・いちばん最後に 作る）
- 冒険は オンラインで 友達と 最大4人で 遊べるように する。
- バトルモード（MONZ RUMBLE・MYTHCLASH）も オンラインで 友達と 対戦できるように する。
- 気をつけること：オンラインには 通信の サーバーが いる（GitHub Pages だけでは できない）。使う サービスと 費用は 作る前に 企画者に 確認する。
- 今は 1人用で 作るが、あとで オンラインに しやすいように、計算は `src/core/` に まとめ、乱数は 種から 決める。
