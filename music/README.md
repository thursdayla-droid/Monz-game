# 曲の受け取り口

企画者が用意した曲（mp3 / m4a / wav）をここに置く。
Claude Code が、音量をそろえ・つなぎ目を整えてから `public/assets/bgm/` に入れ、`src/audio/bgmFiles.ts` に登録する。

| 場面 | ファイル名の例 | 長さの目安 | 流し方 |
| --- | --- | --- | --- |
| タイトル | title.mp3 | 1分半〜2分半 | くり返す |
| 質問 | question.mp3 | 1分半〜2分半 | くり返す |
| ドラゴン | dragon.mp3 | 30秒〜1分 | くり返す |
| 誕生 | hatch.mp3 | 20〜40秒 | 1回（終わるとホームの曲へ） |
| ホーム | home.mp3 | 2〜3分 | くり返す |

- 歌・ラップなし（インスト）。
- アプリで公開してよい（商用利用できる）曲だけを使う。
